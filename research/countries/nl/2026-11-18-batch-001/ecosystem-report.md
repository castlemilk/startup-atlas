## Integration and review rules

The country packet should preserve the following distinctions through schema validation and PR review:

- **Company identity:** resolve canonical domains, aliases, rebrands, parent/subsidiary links and newly formed entities using explicit evidence. A similar name, acquisition or merger announcement alone does not prove legal-entity continuity.
- **Geography:** keep headquarters, incorporation jurisdiction, operating facilities, programme location and investor offices separate. Record the source and temporal scope of each location.
- **Dates and unknowns:** preserve year/month/day precision. Retrieval date is not founding, incorporation, announcement or closing date. Unknown values remain null in staging or absent in a schema that does not accept null.
- **Financing:** preserve original currency and stated transaction type. Distinguish a round from cumulative funding, valuation, debt, grant, secondary transaction and a fund commitment. A portfolio page supplies no event-level investor role.
- **Professional people data:** use public, explicit founder-role evidence; do not infer founders from a current leadership page or collect personal contact details.
- **Delivery state:** a researched claim, validated record, commit, draft PR, merged change and deployed publication are different states. This report confers no approval to merge, release or activate crawler sources.

Before integration, review the latest repository revision and candidate ledger, recompute duplicate and disposition totals, and reconcile any concurrent company additions. The machine manifests remain the authority for the bounded batch's counts, schema validation results, precise file inventory and remaining coverage.
