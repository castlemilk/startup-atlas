## Progressive enhancement and focus contract

The authored static document contains all three fictional dossiers, complete claims and source links. Without JavaScript, inspection links reach those dossiers and interactive review controls remain unavailable. Enhanced review uses supplied synthetic envelopes; disabling or disposing the enhancement restores static evidence. There is no service connection or real-record write.

Native links, labelled inputs/selects, buttons, headings, disclosure elements and a status region carry semantics. Explicit entity or claim navigation has an addressable heading; ordinary asynchronous updates must not steal focus. Close returns to a usable opener, with the results heading as fallback. Newer selection/claim intent wins over older pending responses. The controls and inspector owners must agree the final focus handoff before operational integration.

The CSS uses container-based reflow around 900px and 600px, natural document scrolling, wrapping IDs/URLs/full record values, visible focus and 44px minimum interactive targets. These are source properties and design intent; their rendered adequacy is unverified.
