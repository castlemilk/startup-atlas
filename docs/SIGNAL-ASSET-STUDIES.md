# Signal identity studies · r1

**Experimental artwork, not a selected logo or production identity.** Three original editable constructions extend the light Signal system. No existing logo, navigation symbol or data view is changed. These are independent authored concepts, not recovered code or generated screenshots. They do not implement Bencho or SPEC-01 Hardware.

## Direction

Make Atlas feel like a precise research instrument: an intentional opening, a record brought forward, or an interface that joins two contexts. Keep the surrounding UI quiet. Use broad graphite silhouettes and one cobalt action plane, not HUD rings, rockets, arbitrary network dots or fake scientific annotations. Transparent outside areas and cutouts must remain genuinely clear. Edges are deliberately crisp; softness belongs to host controls rather than every symbol.

Gamma MCP was queried on 17 November 2026: the **Gamma** system supports near-white surfaces, one cobalt action role, ink-tinted depth and separate light/dark roles. This informs the role discipline, not a wholesale token or font import. Gamma's separate system named **Signal** is a vermilion/pill design and is not Atlas Signal. Atlas retains its own `#111318` / `#315EFB` light and `#F4F6FA` / `#9AAFFF` dark palette. No Gamma component or third-party logo source is copied.

## Three constructions

### Aperture

A tapered A-like survey opening, crossed by one short active shelf. The triangular negative space and strong upright silhouette should read before the letter. The shelf is intentionally separated in color but belongs to the same mass in monochrome. Best candidate for further identity exploration because it is compact without borrowing a stock compass. Risk: it is still an abstract A, so selection requires comparison with the existing identity and distinctiveness review.

### Folio

Two offset, open record frames with one small selected line. Offset corners carry the idea of an indexed archive rather than a generic document pictogram. Best suited to an editorial collection seal or research-library illustration; not recommended as a replacement for the existing search icon. The staggered negative-space rhythm must remain visible.

### Relay

Two deliberately separate brackets joined by one active bridge. It echoes the existing Coupling material metaphor without tracing its image. Useful as an MCP/context-transfer spot mark. It is less differentiated as a master logo and should remain a feature study. It never indicates a successful connection or live status without accompanying factual UI text.

## Delivery and limits

Nine SVG exports: three genuinely distinct families, each in light, dark and monochrome. Each uses a 128-unit viewBox and named `structure` / `selection` layers, no background, font, raster, filter, remote resource or script. Minimum intended size: 32px; at 16px use an existing approved Atlas icon rather than downscaling these studies. Dark exports are for dark surfaces, not automatic theme detection.

[Review gallery and downloads](../web/assets/design-lab/signal-explorations/index.html). [Machine-readable asset manifest](../web/assets/design-lab/signal-explorations/manifest.json). Reproduce byte-stable SVGs and hashes with `python3 scripts/make-signal-studies.py`. Static geometry is illustrative, not a scientific or physical model; no global originality or trademark-clearance claim is made.

Use `img` with an appropriate accessible label when meaningful; hide purely decorative repetitions from assistive technology. Do not bake an unapproved mark into the app header or favicon. Published asset availability does not imply identity selection.

## Review evidence

Retain all three as separate studies; prefer Aperture for the next identity round, Folio for collections and Relay for integration art. Rendered with installed Inkscape and inspected at 128px in light, dark and mono, plus actual 32px light exports. Broad silhouettes and internal gaps remain readable; the smallest selected line in Folio is intentionally sparse. Exterior and intended aperture pixels were checked for real alpha. Automated tests check nine hash-pinned exports, byte-stable regeneration, constrained SVG elements and theme-invariant paths. The static site build passed. No production header integration or browser interaction changes are claimed.
